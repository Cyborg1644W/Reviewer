III. What Is Inheritance?

Inheritance is an OOP mechanism that allows one class to acquire properties and behaviors from another class.

  • Simple idea: a child class can reuse what already exists in a parent class.
  • Example: Animal → Dog. A Dog is an Animal, so common animal behavior can be placed in Animal and reused by Dog.
The attached lesson specifically demonstrates that the Dog class inherits the eat() method from Animal.

IV. Important Terms

TermMeaning
Parent / SuperclassThe class from which another class inherits.
Child / SubclassThe class that inherits from another class.
extendsJava keyword used to establish class inheritance.
Inherited memberAn accessible field or method available through inheritance.
IS-A relationshipThe child is a type of the parent, e.g., Dog IS-A Animal.

V. Basic Syntax

class ChildClass extends ParentClass {
  // child attributes and methods
}

Example:

class Dog extends Animal {
}

Dog is the child/subclass; Animal is the parent/superclass.

VI. Basic Animal–Dog Example

class Animal {
  void eat() {
    System.out.println("Animal is eating.");
  }
}
class Dog extends Animal {
}
public class Main {
  public static void main(String[] args) {
    Dog d = new Dog();
    d.eat();
  }
}
Animal is eating.

Explanation: eat() is declared in Animal. Because Dog extends Animal, the Dog object can access the inherited method.

VII. Child Class With Its Own Behavior

class Animal {
  void eat() {
    System.out.println("Animal is eating.");
  }
}
class Dog extends Animal {
  void bark() {
    System.out.println("Dog is barking.");
  }
}
public class Main {
  public static void main(String[] args) {
    Dog d = new Dog();
    d.eat();
    d.bark();
  }
}
Animal is eating.
Dog is barking.

The child can use inherited behavior and can also define its own behavior.

VIII. Why Use Inheritance?

  • Code reuse: common code can be reused by several child classes.
  • Reduced duplication: common attributes and methods do not need to be repeated.
  • Easier maintenance: common behavior can be maintained in the parent.
  • Specialization: child classes can add features specific to their roles.
  • Logical modeling: inheritance can represent meaningful IS-A relationships.
The first three benefits (code reuse, reduced duplication, easier maintenance) are explicitly identified in the attached lesson.

IX. IS-A Versus HAS-A

Use inheritance when the relationship is logically IS-A.

  • Dog IS-A Animal → inheritance is appropriate.
  • Student IS-A Person → inheritance is appropriate.
  • Faculty IS-A Person → inheritance is appropriate.
  • Student HAS-A Address → use a field/association rather than making Address the superclass.
class Student extends Person {
}

class Student {
  Address address;
}

The first form is inheritance (IS-A); the second is a field/association (HAS-A).

X. University Information System Example

The attached lesson presents Person as a shared parent and Student, Faculty, and Administrator as specialized roles.

class Person {
  String name;
  int id;
  void displayInfo() {
    System.out.println("Name: " + name);
    System.out.println("ID: " + id);
  }
}
class Student extends Person {
  void enroll() {
    System.out.println(name + " is enrolling in courses.");
  }
}
class Faculty extends Person {
  void teach() {
    System.out.println(name + " is teaching.");
  }
}
public class Main {
  public static void main(String[] args) {
    Student s = new Student();
    s.name = "Juan";
    s.id = 1001;
    s.displayInfo();
    s.enroll();
    Faculty f = new Faculty();
    f.name = "Maria";
    f.id = 2001;
    f.displayInfo();
    f.teach();
  }
}
Name: Juan
ID: 1001
Juan is enrolling in courses.
Name: Maria
ID: 2001
Maria is teaching.

Student can use the inherited name, id, and displayInfo() from Person, while enroll() belongs specifically to Student.

XII. Inheritance and Constructors

A child constructor can call a matching parent constructor using super(...).

class Person {
  String name;
  Person(String name) {
    this.name = name;
  }
}
class Student extends Person {
  Student(String name) {
    super(name);
  }
}
public class Main {
  public static void main(String[] args) {
    Student s = new Student("Juan");
    System.out.println(s.name);
  }
}
Juan

this refers to the current object. super refers to the parent class and can invoke a parent constructor.

XIV. Inheritance and Method Overriding

Inheritance also supports polymorphism. A child can provide its own implementation of an inherited method.

class Animal {
  void sound() {
    System.out.println("Animal makes a sound.");
  }
}
class Dog extends Animal {
  @Override
  void sound() {
    System.out.println("Dog barks.");
  }
}
public class Main {
  public static void main(String[] args) {
    Dog d = new Dog();
    d.sound();
  }
}
Dog barks.
The attached lesson explains polymorphism as the same method behaving differently depending on the object, and illustrates it with method overriding.
