Lesson 1

Introduction to Object-Oriented Programming

What is OOP?

Definition: Object-Oriented Programming (OOP) is a programming approach that organizes software around objects rather than functions or procedures[cite: 4].
Attributes (Data)
The characteristics of an object[cite: 4]. Examples include name, age, and studentID[cite: 4].
Methods (Behavior)
The actions an object can perform[cite: 4]. Examples include study(), takeExam(), and attendClass()[cite: 4].

Java is primarily an Object-Oriented Programming language, meaning most programs are built using classes and objects[cite: 4]. OOP helps developers create software that is:

  • Modular[cite: 4].
  • Reusable[cite: 4].
  • Maintainable[cite: 4].
  • Secure[cite: 4].
  • Scalable[cite: 4].

Basic Concepts of OOP Memorize

  • 1
    Class
    A blueprint for creating objects[cite: 4]. The class defines what properties an object should have[cite: 4].
  • 2
    Object
    An instance of a class[cite: 4].
  • 3
    Attributes
    Store information about an object[cite: 4].
  • 4
    Methods
    Define behaviors of an object[cite: 4].
  • 5
    Constructor
    Initializes objects[cite: 4].

The Four Pillars of OOP

  • A
    Encapsulation
    The process of hiding data and allowing access only through controlled methods[cite: 4]. Benefits include data security, prevention of unauthorized modification, and improved program reliability[cite: 4].
  • B
    Inheritance
    Allows one class to acquire properties and behaviors from another class[cite: 4]. Benefits include code reuse, reduced duplication, and easier maintenance[cite: 4].
  • C
    Polymorphism
    Means "many forms"[cite: 4]. The same method can behave differently depending on the object[cite: 4]. (e.g., Method Overriding)[cite: 4].
  • D
    Abstraction
    Hides implementation details and shows only essential features[cite: 4]. (e.g., Using an ATM to withdraw money without needing to know how the bank processes the transaction internally)[cite: 4].

Major Programming Paradigms Understand

Paradigm Main Focus & Characteristics
ProceduralFocuses on procedures or functions executed step by step[cite: 4]. Uses standalone functions where data and behavior are separate[cite: 4]. Focuses on 'how' to solve a problem[cite: 4].
Object-OrientedPrograms are built using classes and objects[cite: 4]. Data and behavior are grouped together[cite: 4]. Focuses on 'what' the object is and does[cite: 4].
FunctionalEmphasizes the use of functions and immutable data[cite: 4]. Java supports this through Lambda Expressions, Stream API, and Functional Interfaces[cite: 4].
Event-DrivenProgram execution is controlled by events such as button clicks, mouse actions, or keyboard input[cite: 4].
DeclarativeFocuses on what should be done rather than how to do it[cite: 4]. The programmer specifies the desired result, while Java determines processing details[cite: 4].
Lesson 2

Introduction to Java Programming

What is Java?

Overview: Java is a high-level, object-oriented, and platform-independent programming language developed by Sun Microsystems (now owned by Oracle) in 1995[cite: 5].

Key Features of Java

  • 1
    Platform Independent
    Java programs run on any device with a Java Virtual Machine (JVM)[cite: 5]. This is known as "Write Once, Run Anywhere (WORA)"[cite: 5].
  • 2
    Object-Oriented
    Based on the concepts of classes and objects, making programs modular, reusable, and easier to maintain[cite: 5].
  • 3
    Simple
    Has a straightforward syntax and removes many complex features found in languages like C++[cite: 5].
  • 4
    Secure
    Provides built-in security features such as bytecode verification and automatic memory management[cite: 5].
  • 5
    Robust
    Exception handling and garbage collection help make Java applications reliable[cite: 5].
  • 6
    Multithreaded
    Supports running multiple tasks simultaneously[cite: 5].
  • 7
    High Performance
    Although interpreted by the JVM, Just-In-Time (JIT) compilation improves execution speed[cite: 5].

How Java Works Understand

  • 1Write the source code (.java file)[cite: 5].
  • 2Compile it using the Java compiler (javac), which produces bytecode (.class file)[cite: 5].
  • 3The JVM executes the bytecode on any operating system that supports Java[cite: 5].

The Main Method Breakdown

The main() method is the starting point of a traditional standalone Java application[cite: 5].

Java Syntax and Rules Memorize

  • Case-Sensitive: Java distinguishes between uppercase and lowercase letters (e.g., System is different from system)[cite: 5].
  • Semicolons: Most Java statements end with a semicolon ;[cite: 5].
  • Curly Braces: Java uses { and } to define blocks of code[cite: 5].
  • String vs Char: String literals use double quotes "", while single characters use single quotes ''[cite: 5].
  • Strongly Typed: Variables must have declared data types[cite: 5].

Identifiers & Keywords

Identifiers
A name given to programming elements like classes, variables, methods, objects, and packages[cite: 5]. Can contain letters, digits, _, and $[cite: 5]. Cannot begin with a digit, contain spaces, or be a keyword[cite: 5].
Keywords
Reserved words that have special meanings in Java (e.g., class, public, void, static)[cite: 5]. You cannot use a keyword as a variable name[cite: 5].
