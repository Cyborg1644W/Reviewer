1. Introduction to Java

Java is a high-level, object-oriented, platform-independent language developed by Sun Microsystems (now owned by Oracle) in 1995. It is used for web, mobile, desktop, enterprise, cloud, financial, game, and embedded applications.

Core terms: Java is primarily object-oriented. Programs are organized using classes and objects. Java is designed to be reliable, secure, portable, and versatile for both beginners and professional-scale systems.

Key features of Java - POSSMRH

P - PLATFORM INDEPENDENTJVM + WORA

Java bytecode runs on any device or operating system with a compatible Java Virtual Machine. This is “Write Once, Run Anywhere.”

O - OBJECT-ORIENTEDClasses and objects

Supports modular, reusable, and maintainable programs through OOP concepts.

S - SIMPLEApproachable syntax

Java removes many complex features found in languages such as C++ and has a large standard library.

S - SECURESafer runtime model

Bytecode verification and automatic memory management are built-in security-related features.

M - MULTITHREADEDMultiple tasks

Java can perform multiple tasks concurrently through threads.

R - ROBUSTReliable applications

Exception handling and garbage collection help applications manage errors and memory safely.

H - HIGH PERFORMANCEJIT optimization

The JVM's Just-In-Time compilation can improve execution speed by compiling code during execution.

Applications and advantages

Applications of Java

  • Web applications
  • Android mobile applications
  • Desktop applications
  • Enterprise software
  • Banking and financial systems
  • Cloud and distributed applications
  • Games and embedded systems

Advantages of Java

  • Easy to learn and use
  • Cross-platform compatibility
  • Large standard library
  • Strong community support
  • Automatic memory management (garbage collection)
  • Excellent for large-scale applications

How Java works

  1. Write source code in a .java file.
  2. Compile it with the Java compiler, javac.
  3. The compiler creates bytecode in a .class file.
  4. The JVM executes that bytecode on a supported operating system.
HelloWorld.java  --javac-->  HelloWorld.class (bytecode)  --JVM-->  program runs

2. Java program structure

A traditional standalone Java program starts in its main method. This example identifies every required lesson component.

// A documentation or single-line comment
public class HelloWorld {                 // 1. class declaration + opening brace
    public static void main(String[] args) { // 2. main method + opening brace
        System.out.println("Hello, Java!");  // 3. statement
    }                                    // 4. closing brace for main
}                                        // 4. closing brace for class

1. Class declaration

A class is Java's basic building block. public is an access modifier; class is the keyword; HelloWorld is the class name. If a top-level class is public, its filename must match: HelloWorld.java.

2. Main method

The entry point of a traditional application is public static void main(String[] args).

publicAllows the JVM to access the method.

String[] argsStores command-line arguments.

3. Statement

A statement is an instruction that tells the computer to perform an operation. Example: System.out.println("Hello");. Most Java statements end with a semicolon (;).

4. Braces { }

Braces define a block of code. The outer pair belongs to the class; the inner pair belongs to main().

5. Comments

Comments are notes in source code. The compiler ignores them.

// single-line
/* multi-line */
/** documentation comment */

3. Java syntax and rules

Syntax is the set of rules that determines how Java must be written. Incorrect syntax normally causes a compiler error - like incorrect grammar in a sentence.

A. Java is case-sensitive

Uppercase and lowercase letters are different. Student and student are different identifiers. Likewise, System.out.println() is correct; system.out.println() is not, because System has a capital S.

B. Most statements end with a semicolon
int age = 18;
System.out.println(age);

Missing semicolons on ordinary statements cause compilation errors. Not every Java construct ends with one: an if block itself does not need a semicolon after its closing brace.

if (age >= 18) {
    System.out.println("Adult");
}
C. Curly braces define blocks

Java uses { and } to group statements. Both println calls below belong to the if block.

if (score >= 75) {
    System.out.println("Passed");
    System.out.println("Good job!");
}
D. Identifiers: names for program elements

An identifier is a name given to a class, variable, method, object, or package.

  1. Can contain letters.
  2. Can contain digits.
  3. Can contain underscore (_).
  4. Can contain $, though it is normally avoided in application code.
  5. Cannot begin with a digit.
  6. Cannot contain spaces.
  7. Cannot be a Java keyword.
  8. Is case-sensitive.

Valid: studentNameage2_total
Invalid: 2agestudent nameclass

E. Java keywords (reserved words)

Keywords have special meaning and cannot be used as variable names. The standard reserved-keyword set includes:

4. Object-oriented programming (OOP)

OOP organizes software around objects rather than only functions or procedures. An object represents a real-world entity and contains attributes (data) and methods (behavior).

1. CLASSBlueprint

A definition of what an object will have and what it can do.

2. OBJECTInstance

A specific thing created from a class.

3. ATTRIBUTESData / fields

Information about an object, such as a name, age, or ID.

4. METHODSBehavior

Actions an object can perform, such as study() or takeExam().

Real-world example: Student

Attributes: student ID, name, age.   Methods: study(), takeExam(), attendClass().

class Student {
    String studentId;
    String name;
    int age;

    void study() {
        System.out.println(name + " is studying.");
    }

    void takeExam() {
        System.out.println(name + " is taking an exam.");
    }

    void attendClass() {
        System.out.println(name + " is attending class.");
    }
}

public class Main {
    public static void main(String[] args) {
        Student student1 = new Student();
        student1.studentId = "2026-001";
        student1.name = "Maria";
        student1.age = 18;
        student1.study();
    }
}

Student is the class. student1 is an object. studentId, name, and age are attributes. void means a method does not return a value.

Why use OOP?

Programs become organized

Instead of putting all code in one large file, each class can own a responsibility.

Benefits

  • Modular
  • Reusable
  • Maintainable
  • Secure
  • Scalable

5. The four pillars of OOP

1. Encapsulation - controlled access to data

Encapsulation hides data and allows access through controlled methods. Its benefits are data security, prevention of unauthorized modification, and improved reliability. Commonly, fields are private and public getters/setters provide controlled access.

class BankAccount {
    private double balance; // cannot be changed directly outside this class

    public double getBalance() { return balance; }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
}

2. Inheritance - code reusability

Inheritance lets one class acquire properties and behavior from another. It reduces duplication and makes maintenance easier. Use extends.

class Animal {
    void eat() { System.out.println("Animal eats"); }
}

class Dog extends Animal {
    void bark() { System.out.println("Dog barks"); }
}

// A Dog can use both bark() and the inherited eat().

3. Polymorphism - many forms

The same method call can behave differently depending on the actual object. Method overriding is the common example; @Override asks the compiler to check that a parent method is really being overridden.

class Animal {
    void sound() { System.out.println("Some sound"); }
}
class Dog extends Animal {
    @Override void sound() { System.out.println("Bark"); }
}
class Cat extends Animal {
    @Override void sound() { System.out.println("Meow"); }
}

Animal pet1 = new Dog();
Animal pet2 = new Cat();
pet1.sound(); // Bark
pet2.sound(); // Meow

Although both variables are declared as Animal, Java selects the correct overridden method based on the actual object type.

4. Abstraction - essential features only

Abstraction hides implementation details and shows only what is necessary. An ATM lets a user withdraw money or check a balance without exposing the bank's internal processing.

abstract class Shape {
    abstract double area(); // no implementation here
}
class Circle extends Shape {
    private double radius;
    Circle(double radius) { this.radius = radius; }
    @Override double area() { return Math.PI * radius * radius; }
}

Shape shape = new Circle(2);
System.out.println(shape.area());

Advantages of OOP

  1. Code reusability: inheritance can reuse existing code.
  2. Easy maintenance: each class handles a specific task.
  3. Security: encapsulation protects sensitive data.
  4. Scalability: new classes can be added more easily.
OOP in action - Student Information System: Person can be the parent with shared name, ID, and common behaviors. Student enrolls in courses and takes exams; Faculty encodes grades and manages classes; Administrator manages records and settings. This combines encapsulation (private fields), inheritance (Person → Student/Faculty), polymorphism (overridden methods), and abstraction (shared parent behaviors).

6. Major programming paradigms

A paradigm is a broad way to organize a program and solve problems. Java is strongly object-oriented but supports several paradigms.

ParadigmMain focusKey characteristics / Java support
1. ProceduralFunctions and proceduresStep-by-step, sequential execution; uses functions/methods; suited to simple programs.
2. Object-OrientedObjects and classesClasses/objects, encapsulation, inheritance, abstraction, and polymorphism.
3. FunctionalFunctions and immutable dataJava supports it through lambda expressions, the Stream API, and functional interfaces.
4. Event-DrivenEvents and handlersExecution responds to button clicks, mouse actions, keyboard input, and similar events.
5. DeclarativeDesired resultStates what should happen instead of every step of how; Java can provide declarative-style APIs.
6. LogicFacts and rulesFocuses on rules and logical inference; Java has limited direct support compared with logic languages.
OOP vs. procedural: In procedural code, data and behavior often live separately. OOP groups related data and behavior together inside a class, which can make a large system easier to organize.

7. Constructors

A constructor is a special class member that initializes a newly created object. It runs when new creates the object.

Constructor rules

  • Its name matches the class name exactly.
  • It has no return type - not even void.
  • It can have an access modifier such as public.
  • It initializes attributes and/or runs setup code.
  • A constructor is invoked automatically through new ClassName(...).

Important added detail

If you declare no constructor, Java supplies a default no-argument constructor. Once you declare any constructor yourself, Java does not automatically supply that default constructor.

class Product {
    Product() { // constructor: same name as class, no return type
        System.out.println("Product created");
    }
}

public class Main {
    public static void main(String[] args) {
        Product p1 = new Product();
        Product p2 = new Product();
        Product p3 = new Product();
        Product p4 = new Product();
        // "Product created" is printed four times.
    }
}

The this keyword

this refers to the current object. It is especially useful when a parameter has the same name as a field: this.name means the field, while name means the parameter.

class Product {
    String name;
    float price;

    Product(String name, float price) {
        this.name = name;
        this.price = price;
        System.out.println(name + " created");
    }
}

Product p1 = new Product("Milk", 150.0f);
Product p2 = new Product("Coffee", 250.0f);
Product p3 = new Product("Choco", 100.0f);
Common error corrected: name = name; only assigns a parameter to itself. Use this.name = name; to save the parameter into the object's field. A float literal such as 150.0f needs the trailing f.

Creating an object through user input

Create a class, read values with Scanner, then pass those values to a constructor. Use nextFloat() for a decimal float - not nextFLine().

import java.util.Scanner;

class Product {
    String name;
    float price;
    Product(String name, float price) {
        this.name = name;
        this.price = price;
        System.out.println(name + " created");
        System.out.println(price + " entered");
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Name: ");
        String name = scanner.nextLine();
        System.out.print("Price: ");
        float price = scanner.nextFloat();
        Product p1 = new Product(name, price);
    }
}

Overloading constructors

Constructor overloading creates multiple constructors with different parameter lists so an object can be created with the information available. They must differ in number, types, or order of parameters; changing only a return type is impossible because constructors have no return type.

class Employee {
    String firstName, lastName, position, address, gender;
    int age;

    Employee(String firstName, String lastName, String position,
             String address, String gender, int age) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.position = position;
        this.address = address;
        this.gender = gender;
        this.age = age;
    }

    Employee(String firstName, String lastName, String position) {
        this(firstName, lastName, position, "N/A", "N/A", 0);
    }

    Employee() {
        this("N/A", "N/A", "N/A");
    }
}

Employee e1 = new Employee("Jose", "Rizal", "Doctor");

8. Practice and self-check

Constructor exercise: Dog

The original exercise asks for a program that displays a pet name and age, including examples like Alpha (3), Bravo (2), and Charlie (5). This completed version demonstrates no-argument, one-argument, and two-argument constructors.

class Dog {
    String name;
    int age;

    Dog() {
        this("Alpha", 3);
    }
    Dog(String name) {
        this(name, 0);
    }
    Dog(int age) {
        this("Alpha", age);
    }
    Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    void display() {
        System.out.println(name + " " + age);
    }
}

public class Main {
    public static void main(String[] args) {
        new Dog().display();             // Alpha 3
        new Dog("Bravo", 2).display();  // Bravo 2
        new Dog("Charlie", 5).display();// Charlie 5
    }
}
