III. What Is Inheritance?

Inheritance is an OOP mechanism that allows one class to acquire properties and behaviors from another class.

Simple idea: a child class can reuse what already exists in a parent class.

Example: A Dog is an Animal, so common animal behavior can be placed in Animal and reused by Dog. Specifically, a Dog class inherits the eat() method from Animal.

IV. Important Terms

Term Meaning
Parent / Superclass The class from which another class inherits.
Child / Subclass The class that inherits from another class.
extends Java keyword used to establish class inheritance.
Inherited member An accessible field or method available through inheritance.
IS-A relationship The child is a type of the parent, e.g., Dog IS-A Animal.

V. Basic Syntax & VI. Basic Animal-Dog Example

Syntax:

class ChildClass extends ParentClass {
    // child attributes and methods
}

Example Implementation:

class Animal {
    void eat() {
        System.out.println("Animal is eating.");
    }
}

class Dog extends Animal {
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
    }
}
Output: Animal is eating.

Explanation: eat() is declared in Animal. Because Dog extends Animal, the Dog object can access the inherited method. Dog is the child/subclass; Animal is the parent/superclass.

VII. Child Class With Its Own Behavior

class Animal {
    void eat() {
        System.out.println("Animal is eating.");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking.");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}
Output:
Animal is eating.
Dog is barking.

The child can use inherited behavior and can also define its own behavior.

VIII. Why Use Inheritance?

  • Code reuse: common code can be reused by several child classes.
  • Reduced duplication: common attributes and methods do not need to be repeated.
  • Easier maintenance: common behavior can be maintained in the parent.
  • Specialization: child classes can add features specific to their roles.
  • Logical modeling: inheritance can represent meaningful IS-A relationships.

IX. IS-A Versus HAS-A

Use inheritance when the relationship is logically IS-A.

  • Dog IS-A Animal (Inheritance is appropriate)
  • Student IS-A Person (Inheritance is appropriate)
  • Faculty IS-A Person (Inheritance is appropriate)

Student HAS-A Address → use a field/association rather than making Address the superclass.

class Student extends Person {
    Address address; // Composition/Association, not inheritance
}

X. University Information System Example

Person is a shared parent, while Student, Faculty, and Administrator are specialized roles.

class Person {
    String name;
    int id;
    
    void displayInfo() {
        System.out.println("Name: " + name);
        System.out.println("ID: " + id);
    }
}

class Student extends Person {
    void enroll() {
        System.out.println(name + " is enrolling in courses.");
    }
}

class Faculty extends Person {
    void teach() {
        System.out.println(name + " is teaching.");
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "Juan";
        s.id = 1001;
        s.displayInfo();
        s.enroll();
        
        Faculty f = new Faculty();
        f.name = "Maria";
        f.id = 2001;
        f.displayInfo();
        f.teach();
    }
}
Output:
Name: Juan
ID: 1001
Juan is enrolling in courses.
Name: Maria
ID: 2001
Maria is teaching.

XI. What Does the Child Inherit?

Student can use the inherited name, id, and displayInfo() from Person, while enroll() belongs specifically to Student.

Hierarchy:
Person (name, id, displayInfo())
↓
Student (enroll())

XII. Inheritance and Constructors

A child constructor can call a matching parent constructor using super(...).

class Person {
    String name;
    Person(String name) {
        this.name = name;
    }
}

class Student extends Person {
    Student(String name) {
        super(name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student("Juan");
        System.out.println(s.name);
    }
}
Output: Juan

XIII. this Versus super

Keyword Meaning Example
this Current object this.name = name;
super Parent class (can invoke parent constructor) super(name);

XIV. Inheritance and Method Overriding

Inheritance also supports polymorphism. A child can provide its own implementation of an inherited method.

class Animal {
    void sound() {
        System.out.println("Animal makes a sound.");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks.");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}
Output: Dog barks.

Note: Polymorphism means the same method behaves differently depending on the object, illustrated here via method overriding.

XV. Types of Inheritance Structures

  • 1. Single inheritance: class Student extends Person { }
  • 2. Multilevel inheritance: class Employee extends Person { } → class Manager extends Employee { }
  • 3. Hierarchical inheritance: class Student extends Person { } and class Faculty extends Person { }

XVI. Common Mistakes

  • Missing extends: Correct: class Dog extends Animal {}
  • Reversing the relationship: Usually Dog extends Animal because Dog IS-A Animal.
  • Confusing this and super: this = current object; super = parent class.
  • Using inheritance without an IS-A relationship: Use composition/association when the relationship is HAS-A.
  • Forgetting child-specific behavior: A child can add its own fields and methods.
