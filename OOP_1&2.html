Topic 1

Introduction to Java

What is Java?

Core Definition: Java is a high-level, object-oriented, and platform-independent programming language[cite: 2]. It was developed by Sun Microsystems in 1995 (now owned by Oracle)[cite: 2].

Key Features of Java Memorize

  • 1
    Platform Independent
    Java programs run on any device with a Java Virtual Machine (JVM). This is known as "Write Once, Run Anywhere (WORA)"[cite: 2].
  • 2
    Object-Oriented
    Based on classes and objects, making programs modular, reusable, and easier to maintain[cite: 2].
  • 3
    Simple & Secure
    Has straightforward syntax and built-in security features like bytecode verification and automatic memory management (Garbage Collection)[cite: 2].
  • 4
    Robust & Multithreaded
    Features exception handling to make applications reliable, and supports running multiple tasks simultaneously[cite: 2].
  • 5
    High Performance
    Uses Just-In-Time (JIT) compilation to improve execution speed, even though it is interpreted by the JVM[cite: 2].

How Java Works Understand

  • 1Write the source code and save it as a .java file[cite: 2].
  • 2Compile it using the Java compiler (javac), which produces bytecode in a .class file[cite: 2].
  • 3The JVM executes the bytecode on any operating system that supports Java[cite: 2].

Applications of Java

  • Web and Android mobile applications[cite: 2].
  • Desktop and Enterprise software[cite: 2].
  • Banking, financial systems, cloud, and distributed applications[cite: 2].
  • Games and embedded systems[cite: 2].
Topic 2

Object-Oriented Programming (OOP)

What is OOP?

Definition: Object-Oriented Programming (OOP) is a programming approach that organizes software around objects rather than functions or procedures[cite: 3].
Attributes (Data)
The characteristics of an object (e.g., name, age, studentID)[cite: 3].
Methods (Behavior)
The actions an object can perform (e.g., study(), takeExam())[cite: 3].
Class
A blueprint for creating objects. It defines what properties an object should have[cite: 3].
Object
An instance of a class[cite: 3].

The Four Pillars of OOP Memorize

  • 1
    Encapsulation
    The process of hiding data and allowing access only through controlled methods[cite: 3]. It improves security and program reliability[cite: 3]. Example: Using a private balance field and a public getBalance() method[cite: 3].
  • 2
    Inheritance
    Allows one class to acquire properties and behaviors from another class, promoting code reuse[cite: 3]. Example: A Dog class extends an Animal class to inherit its eat() method[cite: 3].
  • 3
    Polymorphism
    Means "many forms." The same method can behave differently depending on the object[cite: 3]. Example: Both Dog and Cat classes override a makeSound() method differently[cite: 3].
  • 4
    Abstraction
    Hides implementation details and shows only essential features[cite: 3]. Example: Using an ATM without needing to know how the bank processes the transaction internally[cite: 3].

Programming Paradigms Comparison

Paradigm Main Focus
ProceduralFocuses on functions and procedures executed step by step[cite: 3]. Data and behavior are separate[cite: 3].
Object-OrientedPrograms are built using classes and objects[cite: 3]. Data and behavior are grouped together[cite: 3].
FunctionalEmphasizes the use of functions and immutable data (supported in Java via Lambda and Streams)[cite: 3].
Event-DrivenProgram execution is controlled by events like button clicks or mouse actions[cite: 3].
DeclarativeFocuses on what should be done rather than how to do it[cite: 3].

Core Syntax Rules Memorize

  • 1Case-Sensitive: Java distinguishes between uppercase and lowercase letters (e.g., `System` is not `system`)[cite: 2].
  • 2Semicolons: Most Java statements (instructions performing operations) end with a semicolon `;`[cite: 2].
  • 3Curly Braces: Java uses `{` and `}` to define and group blocks of code[cite: 2].
  • 4File Naming: If a class is declared public, the filename should match the class name[cite: 2].

Variables and Data Types

Java is a strongly typed language, meaning variables must have declared types[cite: 2].

Primitive Types
int (whole number), double (decimal number), char (single character, uses single quotes), boolean (true or false)[cite: 2].
Reference Types
String (text, normally enclosed in double quotation marks)[cite: 2].

Identifiers & Naming Conventions

Identifier Rules: Can contain letters, digits, `_`, and `$`[cite: 2]. Cannot begin with a digit, contain spaces, or be a Java keyword[cite: 2]. Is case-sensitive[cite: 2].

Programming Preparation

Code Guide

Use these guides to understand standard Java class construction and OOP implementations.

Basic Class Structure and Method Execution
  • Declare the class using `public class ClassName`[cite: 2].
  • Include the entry point: `public static void main(String[] args)`[cite: 2].
  • Declare variables using standard types: `String name = "Maria";`, `int age = 20;`[cite: 2].
  • Output text to the console using `System.out.println();`[cite: 2].
  • Ensure every executable statement ends with a semicolon `;`[cite: 2].
Implementing OOP: Classes, Objects, and Constructors
  • Define a blueprint class with attributes (e.g., `class Student { String name; }`)[cite: 3].
  • Define methods to represent behavior (e.g., `void study() { ... }`)[cite: 3].
  • Use a constructor to initialize the object. The constructor shares the exact name of the class (e.g., `Student(String name)`)[cite: 3].
  • Instantiate the object in your main method using the `new` keyword: `Student s1 = new Student("Maria");`[cite: 3].
Implementing Inheritance & Polymorphism
  • Create a parent class (e.g., `Animal` with method `makeSound()`)[cite: 3].
  • Create a child class using the `extends` keyword (e.g., `class Dog extends Animal`)[cite: 3].
  • Override the parent method in the child class using the `@Override` annotation[cite: 3].
  • Demonstrate polymorphism by instantiating the child class as the parent type: `Animal a1 = new Dog();`[cite: 3].
